## Learning Journey

This portfolio documents a data analysis learning journey with an emphasis on data privacy and security.

Starting with Python, the focus was on mastering data processing with Pandas and NumPy while ensuring data integrity. Learning SQL involved query syntax, database design, and secure data access practices.

Progressing to data visualization tools and Excel deepened understanding of how to present insights clearly. In machine learning, the priority was on building reliable models while protecting data privacy throughout the pipeline.

The overarching goal: become a well-rounded data analyst who can handle real-world business problems end-to-end — from raw data to actionable insight.
