# Python 腳本執行順序（建議）

以下路徑以 `pipeline_config.py` 為準（`MDB` → `{檔名}_csv` → `analysis_output`）。

## 標準流程

| 順序 | 腳本 | 說明 |
|------|------|------|
| **1** | `export_mdb_to_csv.py` | 從 `.mdb` 匯出全部 CSV 到子資料夾。**關閉 Access 再執行。** |
| **2**（選用） | `anonymize_csvs.py` | 去識別後寫入 `*_csv_anonymized`，**不覆寫**原始 CSV。對外分享用匿名版。 |
| **3** | `analyze_business.py` | 讀 `sale`/`cust`/`prod` 產生圖表與 RFM／滯銷 CSV、`analysis_output/report.html`。 |
| **4** | `dashboard.py` | 互動儀表板；**請先完成步驟 3**。執行：`python -m streamlit run dashboard.py` |

## 一鍵（略過步驟 2）

| 腳本 | 說明 |
|------|------|
| `run_pipeline.py` | 連續執行 **1 + 3**（匯出 → 分析）。可加 `--analyze-only`、`--open`。 |

## 選用工具

| 腳本 | 說明 |
|------|------|
| `preview_core_csvs.py` | 快速預覽核心 CSV 欄位與筆數。 |
| `cleanup_low_value_csvs.py` | 刪除低價值 CSV（`p#######`/`s#######`、before、報表快照、BOM 等），**兩個 CSV 目錄**都會掃描（若存在）。 |

## 設定

| 檔案 | 說明 |
|------|------|
| `pipeline_config.py` | 集中設定 `MDB` 檔名與對應 CSV／分析輸出路徑。 |

## 依賴

```text
pip install -r requirements.txt
```
