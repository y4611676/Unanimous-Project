# Python 腳本執行順序（建議）

以下路徑以 `pipeline_config.py` 為準（`MDB` → `{檔名}_csv` → `analysis_output`）。

## 標準流程

| 順序 | 腳本 | 說明 |
|------|------|------|
| **1** | `export_mdb_to_csv.py` | 從 `.mdb` 匯出全部 CSV 到子資料夾。**關閉 Access 再執行。** |
| **2**（選用） | `anonymize_csvs.py` | 去識別後寫入 `*_csv_anonymized`，**不覆寫**原始 CSV。對外分享用匿名版。 |
| **3** | `analyze_business.py` | 跑 A–H 九個分析章節，產出 30+ CSV、PNG，以及綜合版 `analysis_output/report.html`（雙擊開啟）。 |
| **4** | `dashboard.py` | Streamlit 互動儀表板，9 個分頁。**請先完成步驟 3**。執行：`python -m streamlit run dashboard.py` |

## 一鍵（略過步驟 2）

| 腳本 | 說明 |
|------|------|
| `run_pipeline.py` | 連續執行 **1 + 3**（匯出 → 分析）。可加 `--analyze-only`、`--open`。 |

## 綜合版涵蓋的分析主題

| 章節 | 主題 | 產出 |
|------|------|------|
| 營收 | 月營收趨勢 | `monthly_revenue.csv`、`monthly_revenue_trend.png` |
| A 毛利 | 月毛利、商品／客戶／分類毛利、負毛利品項 | `monthly_margin.csv`、`product_margin.csv`、`product_negative_margin.csv`、`customer_margin.csv`、`class_margin.csv` |
| B 庫存 | ABC、呆料金額化、分類週轉、安全庫存、疑似缺貨 | `abc_analysis.csv`、`products_stale_over_one_year.csv`、`class_turnover.csv`、`safety_stock_breach.csv`、`out_of_stock_with_recent_sales.csv` |
| C 客戶 | RFM 分數 + 分群、Pareto 80/20、Cohort 留存、新客 vs 回頭、地區、類型 | `rfm_scored.csv`、`rfm_segment_summary.csv`、`customers_no_trade_in_last_year.csv`、`cohort_retention.csv`、`new_vs_repeat.csv`、`area_revenue.csv`、`kind_revenue.csv` |
| D 購物籃 | 商品對關聯（support / confidence / lift） | `basket_pairs.csv` |
| E 供應商 | 集中度、成本波動、進多賣少 / 賣多沒補 | `supplier_ranking.csv`、`cost_drift.csv`、`overstocked.csv`、`underreplenished.csv` |
| F 現金流 | AR 帳齡、DSO、壞帳名單、月現金流 | `ar_aging.csv`、`bad_debt_risk.csv`、`monthly_cashflow.csv` |
| G 業務員 | 業績、毛利、客戶集中度 | `salesrep_ranking.csv`、`salesrep_customer_mix.csv` |
| H 預測 | 下月營收、季節性、異常月份（z-score） | `revenue_anomalies.csv` |

## 選用工具

| 腳本 | 說明 |
|------|------|
| `preview_core_csvs.py` | 快速預覽核心 CSV 欄位與筆數。 |
| `cleanup_low_value_csvs.py` | 刪除低價值 CSV。 |
| `notebooks/business_overview.ipynb` | Jupyter Notebook 版，可講故事／轉 PDF。 |

## 只跑特定章節

```bash
# 只跑毛利、庫存、客戶
python analyze_business.py --only profit inventory customer
```

## 設定

| 檔案 | 說明 |
|------|------|
| `pipeline_config.py` | 集中設定 `MDB` 檔名與對應 CSV／分析輸出路徑。 |
| `src/` | 分析邏輯模組（每章節一個檔）、共用 I/O、圖表、HTML 報告。 |
